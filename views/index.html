Frequently Asked Questions

Can I cancel an appointment?
Yes, you can cancel any session directly from your "My Schedule" dashboard. The time slot will instantly become available for other students to book.
I forgot my auto-generated ID. What do I do?
Your auto-generated ID (e.g., S101 or T101) is required for login. If you lose it, please contact the system administrator to retrieve it using your registered name.
Can a time slot be double-booked?
No. Our backend SQLite database automatically checks constraints to ensure that once a time slot is reserved by a student, it is hidden from others.

This application utilizes a Single Page Application (SPA) frontend architecture built with HTML5. It has been completely restyled using pure custom CSS to achieve a modern, rounded interface without external frameworks.

The backend runs on a lightweight Deno server utilizing the Oak framework within an MVC (Model-View-Controller) structure, securely storing data within a local SQLite database.

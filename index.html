This application utilizes a Single Page Application (SPA) frontend architecture built with HTML5. It has been completely restyled using pure custom CSS to achieve this modern, rounded, and aesthetic interface without relying on external frameworks.

The backend runs on a lightweight Deno server utilizing the Oak framework for RESTful routing, and securely stores data within a local SQLite database. It handles relationship constraints to prevent double-booking.
